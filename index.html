How to play

There is no winner and no scoring. The only rule that matters is that whoever draws the card answers it first, and everyone else gets a turn after.

  1. Set the floor

    Choose the age of your youngest player. Cards above that age stay in the box.

  2. Draw and answer

    Read it out loud. The person who drew it answers first, then anyone who wants to.

  3. Pass is allowed

    Anyone can skip a card, including the grown-ups. Passing without a reason is fine.

  4. Go up a level

    Start on Spark. Move to Kindling when the table warms up. Bonfire when you mean it.

Why there is an adults-only level on a kids site

Curiosity is not a worksheet. Kids learn how to be honest by watching two adults be honest with each other, and most households run for years without either parent asking the other anything that has not already been answered. The bond between the grown-ups is the room every other conversation happens in.

So Embers is not a bonus deck bolted onto the side. It is the same project pointed one level up. Build the habit at your end of the table and the kids will already know how it is done by the time you hand them a Bonfire card.

A note for parents. Bonfire cards can open things up faster than you expect. Answer them yourself before you ask a kid to. A question you would not answer is not a question you should draw. Embers only appears once you set the table to Adults, and you have to switch it on yourself.
